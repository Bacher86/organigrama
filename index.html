Organigrama Institucional

Arrastrá una tarjeta para moverla, o editala para ponerle un Nivel jerárquico manual (1 = el más alto). Arrastrá desde el punto ⇓ para vincular como dependencia principal; con Shift, como secundaria. Etiquetá el equipo/rama de cada cargo (el primero que le pongas es el principal) para que se vea como un sub-organigrama propio, con su líder arriba. Clic en una línea para quitarla.

La copia JSON sirve para llevar el organigrama a otra compu o restaurarlo con "Importar".

Nuevo cargo

Si lo completás, manda por encima de la jerarquía automática: cuanto más cerca de 1, más arriba queda. Dejalo vacío para que se calcule solo según de quién depende.
El primer equipo que agregues es el "principal" — ahí se arma el recuadro y el sub-organigrama de esa persona. Los que agregues después son afiliaciones: se marcan con un chip y una línea punteada hacia ese recuadro, sin agrandarlo.
Si completás esto, se ignora el campo "Nombre del cargo" de arriba y se crea un cargo por cada línea, todos al mismo nivel y con la misma Área.
Marcá otros cargos si esta persona reporta a más de un superior.
